Getting Started

အသုံးပြုနည်း လမ်းညွှန်

Video Pipeline Suite ကို စတင် Setup လုပ်ပြီး အသုံးပြုပုံကို အဆင့်လိုက် ရှင်းပြထားပါတယ်

Quick Start

အဆင့် ၄ ဆင့်နဲ့ စတင်လိုက်ပါ

1

Download ဆွဲပါ

Download စာမျက်နှာကနေ နောက်ဆုံး Version .zip ဖိုင်ကို Download ဆွဲပြီး Extract (ဖိုင်ဖြည်) လုပ်ပါ

ဒေါင်းလုဒ် →
2

Login ဝင်ပါ

VideoPipelineSuite.exe ကို ဖွင့်ပြီး ပေးထားတဲ့ Username / Password နဲ့ Login ဝင်ပါ

3

Setup Wizard ဖြည့်ပါ

Telegram API, Gemini API, DeepSeek API Key တွေကို Setup Wizard ထဲမှာ တစ်ခါတည်း ထည့်သွင်းပါ

4

Workflow စတင်ပါ

1-Click Pipeline သို့မဟုတ် ကိုယ်သုံးချင်တဲ့ Tool တစ်ခုချင်းစီကို ရွေးပြီး စတင်အသုံးပြုနိုင်ပါပြီ

API Setup

API Setup လမ်းညွှန်

Feature အားလုံး အပြည့်အဝ သုံးနိုင်ဖို့ API Key တွေကို ချိတ်ဆက်ထားဖို့ လိုအပ်ပါတယ်

Telegram API Setup

+

Telegram API (api_id နဲ့ api_hash) ရယူပုံ:

  1. Browser နဲ့ https://my.telegram.org ကို ဖွင့်ပါ
  2. ကိုယ့် Telegram ဖုန်းနံပါတ်နဲ့ Login ဝင်ပါ (Telegram App ထဲ Code ပို့ပေးပါလိမ့်မယ်)
  3. 'API Development Tools' ကို နှိပ်ပါ
  4. App Name နဲ့ Short name နေရာမှာ ကြိုက်ရာနာမည် ထည့်ပါ (Platform မှာ Desktop ရွေးပါ)
  5. 'Create Application' ကို နှိပ်ပါ
  6. ရလာတဲ့ api_id နဲ့ api_hash ကို Copy ကူးပြီး Software ရဲ့ Setup Wizard မှာ ထည့်ပါ

Gemini API Setup (AI Features)

+

Google Gemini API Key ယူနည်း (AI Ad Cutter နဲ့ AI Renamer အတွက်):

  1. https://aistudio.google.com/app/apikey ကို သွားပါ
  2. Google Account နဲ့ Sign In ဝင်ပါ
  3. 'Create API Key' ကို နှိပ်ပါ
  4. 'Create API key in new project' ကို ရွေးပါ
  5. ရလာတဲ့ API Key ကို Copy ကူးပြီး Software ရဲ့ Gemini API Key နေရာမှာ ထည့်ပါ

Free tier နဲ့တင် AI Ad Cutter နဲ့ Batch Renamer ကို ကောင်းကောင်း သုံးနိုင်ပါတယ်

DeepSeek API Setup (Alternative AI)

+

DeepSeek API Key ယူနည်း (Gemini အစားထိုး AI Option):

  1. https://platform.deepseek.com ကို ဖွင့်ပြီး Account ဖွင့်ပါ
  2. Dashboard ထဲက 'API Keys' နေရာကို သွားပါ
  3. 'Create new secret key' ကို နှိပ်ပါ
  4. Key ကို Copy ကူးပြီး Software ထဲမှာ ထည့်သွင်းပါ

DeepSeek က API ကုန်ကျစရိတ် ပိုသက်သာပြီး Internet မလိုတဲ့ Offline Local LLM Option လည်း ပါဝင်ပါတယ်

FAQ

မေးလေ့ရှိသော မေးခွန်းများ

PC အသစ်ပြောင်းသုံးရင် License ကို ဘယ်လိုလုပ်ရမလဲ?

+

License ကို Hardware ID နဲ့ ချိတ်ဆက်ထားတာကြောင့် PC အသစ်မှာ ပြောင်းသုံးချင်ရင် Telegram (@videopipeline) ကို ဆက်သွယ်ပြီး Device Lock Reset (Unbind) လုပ်ပေးဖို့ ပြောနိုင်ပါတယ်

Offline Mode နဲ့ AI Features တွေကို သုံးလို့ရလား?

+

ရပါတယ်! AI Ad Cutter မှာ Offline Local LLM ကို ရွေးသုံးနိုင်သလို Batch Renamer မှာလည်း Internet မလိုတဲ့ Offline Regex Mode ပါဝင်ပါတယ်

Update အသစ်ထွက်လာရင် ဘယ်လို Update လုပ်ရမလဲ?

+

Download စာမျက်နှာကနေ Version အသစ်ကို Download ဆွဲပြီး ဖိုင်ဟောင်းနေရာမှာ Replace (သို့) ဖိုင်သစ်ဖြည်သုံးနိုင်ပါတယ်။ License နဲ့ Settings တွေ ပျောက်မသွားပါဘူး

TikTok Upload မှာ Error တက်ရင် ဘာလုပ်ရမလဲ?

+

TikTok Uploader က Browser Automation (Playwright) ကို သုံးထားတာကြောင့် App ထဲက TikTok Browser Session မှာ TikTok Account ကို Login ပြန်ဝင်စစ်ကြည့်ပေးပါ

Computer Spec ဘယ်လောက်ရှိမှ သုံးလို့ရမလဲ?

+
  • OS: Windows 10 / Windows 11 (64-bit)
  • RAM: အနည်းဆုံး 4 GB (8 GB ရှိရင် ပိုသွက်ပါတယ်)
  • Storage: 500 MB နှင့်အထက် (Video ဖိုင်တွေ သိမ်းဖို့ နေရာပိုလိုပါတယ်)
  • Internet: Download / Upload နဲ့ Cloud AI အတွက် လိုအပ်ပါတယ်
