Quick Start

အဆင့် ၄ ဆင့်ဖြင့် စတင်ပါ

1

ဒေါင်းလုဒ်ရယူပါ

Download Page မှ နောက်ဆုံး Version ကို ဒေါင်းလုဒ်ဆွဲပြီး .zip ဖိုင်ကို ဖြည်ပေးပါ

ဒေါင်းလုဒ် →
2

Login ဝင်ပါ

Software ကိုဖွင့်ပြီး ပေးထားသော Account (Username/Password) ဖြင့် Login ဝင်ပါ

3

Setup Wizard ပြုလုပ်ပါ

4

API Setup

API Setup လမ်းညွှန်

Software အပြည့်အဝ အသုံးပြုနိုင်ရန် API Keys များ Configure ပြုလုပ်ရပါမည်

📱 Telegram API Setup

+

Telegram API (api_id နှင့် api_hash) ရယူနည်း:

  1. Browser ကိုဖွင့်ပြီး https://my.telegram.org သို့ သွားပါ
  2. သင့် Telegram Phone Number ဖြင့် Login ဝင်ပါ
  3. 'API Development Tools' ကိုနှိပ်ပါ
  4. App Name နှင့် Platform ကို ဖြည့်သွင်းပါ (ဘာမဆို ဖြည့်ကြည့်ပါ)
  5. 'Create Application' ကိုနှိပ်ပါ
  6. api_id နှင့် api_hash ကို ကူးယူပြီး Software တွင် ထည့်သွင်းပါ

🤖 Gemini API Setup (AI Features)

+

Google Gemini API Key ရယူနည်း (AI Ad Cutter, AI Renamer အတွက်):

  1. https://aistudio.google.com/app/apikey သို့ သွားပါ
  2. Google Account ဖြင့် Login ဝင်ပါ
  3. 'Create API Key' ကိုနှိပ်ပါ
  4. 'Create API key in new project' ကိုရွေးပါ
  5. API Key ကို ကူးယူပြီး Software ၏ Gemini API Key Field တွင် ထည့်ပါ

💡 Free tier တွင်လည်း ကောင်းမွန်စွာ အသုံးပြုနိုင်ပါသည်

🔬 DeepSeek API Setup (Alternative AI)

+

DeepSeek API Key ရယူနည်း (Gemini အစားထိုး AI Option):

  1. https://platform.deepseek.com သို့ သွားပြီး Account ဖွင့်ပါ
  2. Dashboard မှ 'API Keys' section သို့ သွားပါ
  3. 'Create new secret key' ကိုနှိပ်ပါ
  4. Key ကိုကူးယူပြီး Software တွင် ထည့်သွင်းပါ

💡 DeepSeek သည် Gemini ထက် စျေးသက်သာပါသည်။ Offline Local LLM Option လည်း ရှိပါသည်

FAQ

မေးလေ့ရှိသောမေးခွန်းများ

PC ပြောင်းလဲသောအခါ License ကို ဘာဖြစ်ပါသလဲ?

+

License သည် Hardware နှင့် ချိတ်ဆက်ထားသောကြောင့် PC အသစ်တွင် အသုံးပြုလိုပါက ကျွန်ုပ်တို့ Telegram မှတစ်ဆင့် ဆက်သွယ်ပြီး Transfer ပြုလုပ်ပါ

Offline Mode တွင် AI Features ကို အသုံးပြုနိုင်ပါသလား?

+

ဟုတ်ကဲ့! Local LLM Option ကို AI Ad Cutter တွင် ရွေးချယ်နိုင်ပါသည်။ File Renamer ၏ Offline Regex Mode ကိုလည်း အင်တာနက်မပါဘဲ အသုံးပြုနိုင်ပါသည်

Update တစ်ခု ထွက်လာလျှင် ဘာလုပ်ရမည်နည်း?

+

Download Page မှ နောက်ဆုံး Version ကို ဒေါင်းလုဒ်ဆွဲပြီး ဟောင်းသောဖိုင်ကို Replace ပြုလုပ်ပါ။ License နှင့် Settings များ မပျောက်ပါ

TikTok Upload တွင် Error ဖြစ်ပါက ဘာလုပ်ရမည်နည်း?

+

TikTok Uploader သည် Playwright Automation ကို အသုံးပြုထားသည်။ Browser ကို Update ပြုလုပ်ပါ သို့မဟုတ် TikTok Account ကို Browser တွင် Login ပြန်ဝင်ပါ

Software ကို Computer မည်မျှ Spec လိုအပ်ပါသလဲ?

+
  • OS: Windows 10 / Windows 11 (64-bit)
  • RAM: အနည်းဆုံး 4 GB (8 GB အကြံပြုပါသည်)
  • HDD: 500 MB Free Space
  • Internet: ဒေါင်းလုဒ်/Upload Functions အတွက်

တွေ့ဆုံ မေးမြန်းလိုပါသလား?

ကျွန်ုပ်တို့ Telegram Channel မှတစ်ဆင့် မေးမြန်းနိုင်ပါသည်
