Features အစုံအလင်

Video Workflow အတွက် ပြည့်စုံသော Tools များ

Download, AI Cut, Rename နဲ့ Auto Upload အထိ တစ်နေရာတည်းမှာ အပြည့်အဝ သုံးနိုင်ပါတယ်

Telegram Downloader

Telegram Channel နဲ့ Post တွေက Video တွေကို Filter အစုံနဲ့ မြန်မြန်ဆန်ဆန် Download ဆွဲနိုင်ပါတယ်

  • Save / Forward ပိတ်ထားတဲ့ (Restricted) Channel တွေက Video တွေကိုပါ Download ဆွဲနိုင်ခြင်း
  • Telegram Link ထည့်ပြီး တိုက်ရိုက် Download ဆွဲနိုင်ခြင်း
  • Caption Keyword နဲ့ ရွေးချယ်ရှာဖွေ Download ဆွဲခြင်း
  • Chat ID တွေကို Bulk Export ထုတ်ယူနိုင်ခြင်း
  • Multi-connection Engine နဲ့ အမြန်ဆုံး Download ဆွဲခြင်း
  • Message ID ပါထည့်ပေးလို့ ဖိုင်နာမည်ထပ်နေတာကို ကာကွယ်ပေးခြင်း

Telegram Channel Studio

ကိုယ်ပိုင် Telegram Channel တွေကို Admin တစ်ယောက်လို စနစ်တကျ Manage လုပ်နိုင်ပါတယ်

  • Owner / Admin / Member Badge နဲ့ Channel တွေကို တစ်နေရာတည်း စီမံနိုင်ခြင်း
  • Channel Content Protect (Save/Forward ပိတ်/ဖွင့်) ကို App ထဲကနေ ထိန်းချုပ်နိုင်ခြင်း
  • Video အားလုံးအတွက် Custom Poster Thumbnail တစ်ခုတည်း သတ်မှတ်တင်နိုင်ခြင်း
  • Video ထဲက ကြည်လင်တဲ့ Frame တွေကို Auto Thumbnail ထုတ်ပေးခြင်း
  • Fast Streaming Mode (Resolution & Duration Auto-detect ပါဝင်ခြင်း)
  • Rich HTML Caption Editor နဲ့ Series Template များ သိမ်းထားနိုင်ခြင်း
  • Channel Post တွေရဲ့ Views, Reactions, Pin/Delete တွေကို Manage လုပ်နိုင်ခြင်း
  • Live Countdown ပါဝင်တဲ့ In-App Upload Scheduler

YouTube Downloader

YouTube Video တွေကို Quality အမြင့်ဆုံးနဲ့ ချောမွေ့စွာ Download ဆွဲနိုင်ပါတယ်

  • 4K / 1080p / 720p Quality အစုံ ရွေးချယ် Download ဆွဲနိုင်ခြင်း
  • Browser Cookie ချိတ်ပြီး Bot Check ကို ကျော်ဖြတ်နိုင်ခြင်း
  • Age-restricted Video တွေကိုပါ Download ဆွဲနိုင်ခြင်း

AI Video Ad Cutter

Video အစမှာ ပါတတ်တဲ့ ကြော်ငြာ (Intro Ads) တွေကို AI နဲ့ ရှာဖွေဖြတ်တောက်ပေးပါတယ်

  • Cloud Gemini + DeepSeek + Offline Local LLM ကြိုက်ရာ ရွေးသုံးနိုင်ခြင်း
  • 0.1s Precision Mode နဲ့ အတိအကျ ဖြတ်တောက်ပေးခြင်း
  • Video အစ ၃ မိနစ်စာ Frame တွေကို Auto Scan ဖတ်ပေးခြင်း
  • Ad Template Cache စနစ်ကြောင့် API Credit ကုန်ကျမှု သက်သာခြင်း
  • စစ်ဆေးပြီး Frame Cache တွေကို Auto ပြန်ရှင်းပေးခြင်း
  • NLE Scene Scrubber နဲ့ ကိုယ်တိုင် Manual တိတိကျကျ ဖြတ်လို့ရခြင်း

AI Batch File Renamer

ဖိုင်နာမည်တွေ ရှုပ်နေတဲ့ Video တွေကို AI သုံးပြီး တစ်ပြိုင်နက် နာမည်ပြန်စီပေးပါတယ်

  • Gemini AI Smart Rename စနစ်
  • Dynamic Padding (Ep-001 / Ep-01 အလိုအလျောက် ညှိပေးခြင်း)
  • ဖိုင်နာမည်ထဲက Telegram Message ID တွေကို Auto ဖယ်ရှားပေးခြင်း
  • Internet မလိုတဲ့ Offline Regex Mode
  • မှားသွားရင် 1-Click Undo နဲ့ မူလနာမည် ပြန်ပြောင်းနိုင်ခြင်း
  • Preview Table ထဲမှာ စိတ်ကြိုက် ပြန်ပြင်နိုင်ခြင်း

TikTok & Telegram Uploader

Video တွေကို Schedule သတ်မှတ်ပြီး TikTok နဲ့ Telegram ကို Auto Upload တင်နိုင်ပါတယ်

  • TikTok Auto Upload (Playwright Automation)
  • Telegram Channel / Group / Topic တွေဆီ Upload တင်ခြင်း
  • Date & Time Scheduler စနစ်
  • Live Countdown နဲ့ အချိန်ကျရင် Auto Upload စတင်ပေးခြင်း
  • +15m, +30m, +1h, +3h, +6h, Tomorrow Quick Schedule ခလုတ်များ

Hardware-Lock Security (1–3 PCs)

Account ကို Hardware ID နဲ့ ချိတ်ဆက်ထားပြီး Plan အလိုက် 1–3 PC အထိ စိတ်ချစွာ သုံးနိုင်ပါတယ်

  • CPU + Motherboard UUID + Machine GUID Hardware Lock
  • Account မျှဝေခိုးသုံးခြင်းမှ ကာကွယ်ပေးခြင်း
  • License သက်တမ်းကို App ထဲမှာ တိုက်ရိုက် စစ်နိုင်ခြင်း
  • System Status ထဲကနေ Password အလွယ်တကူ ပြောင်းနိုင်ခြင်း

Setup Wizard

ပထမဆုံး Login ဝင်ချိန်မှာ Telegram, Gemini နဲ့ DeepSeek API တွေကို လွယ်ကူစွာ Setup လုပ်နိုင်ပါတယ်

  • App စဖွင့်တာနဲ့ မချိတ်ရသေးတဲ့ API တွေကို Auto စစ်ပေးခြင်း
  • အဆင့်လိုက် ဖြည့်ရုံ Popup Setup Wizard
  • တစ်ခါ Setup လုပ်ထားရုံနဲ့ ထပ်ခါတလဲလဲ ထည့်စရာမလိုခြင်း
